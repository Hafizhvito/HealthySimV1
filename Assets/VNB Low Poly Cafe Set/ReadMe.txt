[ENG]
The aim for this package is to just set-up things quickly, by providing ready-to-use prefabs of everything. This includes:

- Materials and original palette (including variants you can modify, or create/use new ones). (if you're using URP, then you will need to convert these to URP, this is done with literally just one click from within Unity)
- Prefabs of models ready to place in scene, ready to be animated or manipulated from script (some are actual ready-to-use compositions of models).

*WIP Set -> Unity Prefab option still work-in-progress!

*Make sure to snap things to the grid when using tiles*

*Look at my itch.io page for details*

.-------------------.



--- Description ---

Decorate a minimalist low-poly café with different props, from some food items to useful theme-specific furniture, including structural/building pieces such as walls and floor tiles. This was made for the 3D Paradise Asset Pack Jam #1 in under 30 (31 actually) days, and so more content will be slowly added in the upcoming months.

You may find some important things missing, in which case I encourage you to tell me on my itch.io page, so I can update the set with more models!
