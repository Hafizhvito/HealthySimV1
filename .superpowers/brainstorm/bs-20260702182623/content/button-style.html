Tampilan Tombol FPP/TPP

Bagaimana tombol menampilkan mode aktif dan aksi toggle? Semua pakai style HUD yang sama (dark panel, font bold, outline).

A

Teks mode + arah (rekomendasiku)

Tombol menampilkan mode aktif sekarang di atas, dan tujuan toggle di bawah. Paling informatif, langsung jelas.

TPP → FPP
saat TPP aktif
tap →
FPP → TPP
saat FPP aktif
B

Ikon kamera + badge label

Ikon 📷 atau 👁 di atas, badge kecil TPP/FPP di bawah. Terasa lebih "game-y".

📷 TPP
saat TPP aktif
tap →
👁 FPP
saat FPP aktif
C

Pill toggle TPP | FPP

Satu tombol berbentuk pill dengan dua segmen. Segmen aktif highlight hijau. Terasa seperti toggle switch.

FPP
saat TPP aktif
